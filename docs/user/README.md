# Bezel Evo user guide

[Português (Brasil)](pt-BR/README.md)

Bezel Evo drives the USB system-monitor screens sold as Turing Smart Screen,
TURZX, XuanFang, Kipye, WeAct and their rebrands, on **Windows 10 and 11**. It
has three parts:

- **Bezel Studio**, the editor: design themes by dragging widgets and sensors,
  see them live on the screen, and manage the screen's pictures and videos.
- **Bezel Light**, the tray program that owns the screens: it keeps your saved
  themes running, with their sensors, graphs, transitions and videos, whether
  Studio is open or not.
- **`bezel`**, the command line: the same things from a terminal or a script.

## Getting started

1. [Install Bezel Evo](install.md).
2. [Let Bezel open the screen](permissions.md): only some screens need a driver.
3. [Make your first theme](first-theme.md) and turn on **Live**.
