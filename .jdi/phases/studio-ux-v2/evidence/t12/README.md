# T-12 — confronto prima/dopo

Le immagini «prima» sono le catture conservate dalla galleria T-10 della base
`fb6b42f`. Quelle «dopo» provengono dalla galleria rigenerata per T-12. Il confronto
riguarda soprattutto intestazione e Disposizione: Ordine è dopo Fa parte di,
con quattro comandi e stati disabilitati; le azioni di duplicazione/eliminazione
passano dal menu condiviso. I dati mostrati sono quelli del demo, non valori da
copiare dalle tavole nel prodotto.
